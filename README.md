# OSINT Social Footprint Mapper 🔍

A powerful desktop-based OSINT (Open Source Intelligence) tool built with Python and PyQt6 designed to quickly scan and verify social media profiles and digital footprints across multiple platforms using specific usernames or identifiers.

---

## ✨ Features
- **Multi-Platform Support:** Instantly checks and generates direct profile links across major platforms including:
  - GitHub
  - Instagram
  - Snapchat
  - Reddit
  - Pinterest
  - Twitter/X
- **Fast & Automated:** Replaces manual web searches by automating direct identifier lookups.
- **Modern UI:** Built with an aesthetic PyQt6 dark theme, smooth layout, and custom visual styling.

---

## 🛠️ Tech Stack
- **Language:** Python
- **GUI Framework:** PyQt6
- **Core Modules:** Requests, Sys, PyQt6 Widgets
